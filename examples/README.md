# AiDb 示例

| 示例 | 文件 | 说明 | 运行 |
|------|------|------|------|
| 基本 CRUD | `basic.rs` | 打开/读写/批量/扫描/快照/关闭 | `cargo run --example basic` |
| 备份恢复 | `backup.rs` | 创建备份/验证/恢复 | `cargo run --example backup` |
| 集群路由 | `cluster.rs` | CRC16 槽位计算 / hash tag | `cargo run --features cluster --example cluster` |
